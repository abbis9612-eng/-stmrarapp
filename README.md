# سَنَد — مدرب تنحيف يمشي على قد طاقتك

تطبيق ويب تقدر تثبّته على الجوال (PWA)، عربي بالكامل ويدعم الكتابة من اليمين لليسار. فيه مدرب ذكي (Claude) للناس اللي عندهم وزن زائد **وما عندهم وقت أو طاقة**.
الفكرة الأساسية: **الاستمرار أهم من الكمال**. لذلك التطبيق مبني على أن ما يمر عليك «يوم صفر» مرتين ورا بعض.

## الفرضية المميِّزة

> للشخص المشغول أو المتعب، سند يخلي الاستمرار أسهل بكثير من باقي التطبيقات. السر: **خطة يومية تصغر وتكبر حسب طاقتك ووقتك**، و**تسجيل الأكل بجملة عادية باللهجة الخليجية**، و**هدف سعرات يتعدل تلقائياً من بياناتك الحقيقية**.
> النجاح يُقاس بأن ≥٦٠٪ من المستخدمين يسجلون ٤ أيام أو أكثر بالأسبوع بعد ٣٠ يوم.

## الميزات

- **فحص الطاقة الصباحي**: تختار (تحت / نص نص / فل) ووقتك (دقيقتين / ١٠ / ٢٠)، وتطلع لك ٣ مهمات على قدّك: حركة، أكل، راحة.
- **الخيط (نسيج السدو)**: كل يوم تلتزم فيه ينسج صف. لو فوّتت يوم واحد يمسك الخيط، ولو فوّتت يومين ورا بعض ينقطع. واليوم اللي بعد يوم ضائع يصير «يوم الإنقاذ».
- **المدرب سند**: يفهم «تغديت مندي ولبن» ويقترح تسجيل الأكل بأزرار تأكيد، ويقترح تمرين أو خطة. وإذا ما في اتصال أو مفتاح API، يشتغل **وضع محلي** بقواعد جاهزة، فما تبقى بدون مدرب.
- **قاعدة أكلات خليجية وعربية**: فيها +٦٥ أكلة بحصص واقعية، والبحث يتحمّل الاختلاف بالهمزات والتاء المربوطة.
- **الوزن الاتجاهي**: متوسط متحرك يخفي تذبذب الماء والملح، مع **حرق تكيّفي** يعدّل هدف السعرات بعد ٧ أيام تسجيل على الأقل.
- **مشغّل تمارين** بعدّاد، بدون أدوات، ومناسب للركب.
- **الأمان**: فحص للقُصّر والحمل واضطرابات الأكل وأدوية السكر وGLP-1، وحد أدنى للسعرات (١٢٠٠ للنساء و١٥٠٠ للرجال)، وأقصى نزول ~١٪ من الوزن بالأسبوع.
- **بدون إنترنت**: Service Worker يخزّن الصفحات والخطوط، والمدرب المحلي يرد مباشرة وقت انقطاع الاتصال.
- **تذكير يومي بدون خادم**: ملف تقويم (iCalendar) فيه تنبيه صباحي («كيف طاقتك؟») وتنبيه مسائي («المطبخ يسكّر»)، يشتغل حتى لو التطبيق مسكّر.
- **الخصوصية**: كل البيانات على جهازك، مع نسخة احتياطية واسترجاع بملف JSON.

## المعمارية

```
Next.js 16 (App Router) + React 19 + TypeScript
├─ src/lib/science.ts     ← الحسابات: Mifflin-St Jeor، البروتين، الوزن الاتجاهي، الحرق التكيّفي، الخيط، مهمات اليوم
├─ src/lib/foods.ts       ← قاعدة الأكل + فهم الجمل
├─ src/lib/workouts.ts    ← التمارين
├─ src/lib/safety.ts      ← فحص الأمان
├─ src/lib/store.ts       ← الحالة محفوظة على الجهاز (localStorage)
├─ src/lib/offline-coach  ← المدرب المحلي
└─ src/app/api/coach      ← Claude API: ردود منظمة (JSON schema) + تحقق Zod + fallbacks
```

قرار «محلي أولاً» سببه إن التطبيق لازم يشتغل بدون حساب وبدون إنترنت. **متى نعيد النظر؟** لما نحتاج مزامنة بين الأجهزة أو نصير نقرأ الخطوات من Apple Health / Health Connect. وقتها نضيف خادم (Supabase مثلاً) ونغلّف التطبيق بـ Capacitor.

## تطبيق أندرويد الأصلي (Kotlin + Jetpack Compose)

**رابط التحميل المباشر (آخر نسخة):**
https://github.com/abbis9612-eng/-stmrarapp/releases/latest/download/sanad.apk

كل إصدار على GitHub Releases يحمل أيضاً **لقطات حقيقية** من محاكي أندرويد (فاتح وداكن) لكل الشاشات.

```
android/
├─ core/   ← Kotlin/JVM مستقل (يُختبر بدون Android SDK): العلم، الأكل، التمارين + إطاراتها المتحركة،
│           الأمان، المدرب المحلي، ومحرّك المدرب الذكي (Claude + أي مزوّد متوافق مع OpenAI)
└─ app/    ← Jetpack Compose: هوية السدو، الشاشات، التخزين المحلي، إعدادات المدرب وتشفير المفتاح
```

- **التمارين**: ١٨ تمرين بشخصية مرسومة تتحرك بإطارات مفتاحية (مع كرسي/جدار/حصيرة)، العضلات المستهدفة، الأخطاء الشائعة، والبديل الأسهل/الأصعب. اختبار آلي يتحقق إن أطوال الأطراف منطقية في كل إطار.
- **المدرب الذكي — قالب جاهز**: من شاشة المدرب ← ⚙️ اختر المزوّد (Claude، Google Gemini، Groq، OpenRouter، أو مخصّص)، الصق المفتاح، "اختبر الاتصال"، ثم احفظ. المفتاح يُشفَّر بـ Android Keystore ولا يطلع من الجهاز. بدون مفتاح يشتغل المدرب المحلي.
- **الإخراج المنظّم**: Claude يستخدم JSON schema عبر مكتبة Anthropic الرسمية؛ المزوّدات الأخرى `response_format: json_object` مع إعادة تلقائية بدونه. كل رد يُفحص بصرامة قبل ما يوصل للواجهة.
- **الحركة**: افتتاحية بالشعار ينسج نفسه، الخيط ينسج صفاً عند أول إنجاز، أشرطة وأرقام متحركة، منحنى الوزن يرسم نفسه، واهتزاز خفيف مع كل لمسة.
- **CI**: اختبارات core ← بناء APK موقّع ← نشر Release ← تشغيل على محاكي وإرفاق اللقطات.

بناء محلي: `cd android && ./gradlew :app:assembleRelease` (يحتاج JDK 21 وAndroid SDK)، واختبار المنطق فقط: `cd android/core && ./gradlew test`.

نسخة الويب (Next.js) في جذر المستودع تبقى نموذجاً أولياً ومرجعاً.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ضع ANTHROPIC_API_KEY لتفعيل المدرب الذكي
npm run dev                  # http://localhost:3000
npm test                     # اختبارات الحسابات والأكل والأمان
npm run build && npx next start -p 3100 & npm run shots   # لقطات شاشة فاتح/داكن
```

النموذج الافتراضي `claude-opus-5`، وتقدر تغيّره بـ `COACH_MODEL`.

## خارطة الطريق (الدورات القادمة)

0. صور واقعية للتمارين (تحتاج رصيد توليد صور)، صورة الوجبة ← تقدير، ورسائل صوتية للمدرب

1. وضع رمضان (فطور وسحور) بشكل كامل
2. مراجعة أسبوعية من المدرب («وش نجح؟ وش نعدّل؟»)
3. صورة الوجبة ← تقدير (Claude vision) مع تأكيد المستخدم
4. قراءة الخطوات من الجوال وربطها بمهمة الحركة
5. اختبارات E2E في CI

> سند أداة تدريب سلوكي ومعلومات عامة، ولا يغني عن الطبيب أو أخصائي التغذية.
