# المدرب الذكي السحابي (سند السحابي)

الفكرة: المدرب الذكي يشتغل لكل المستخدمين **بدون ما أحد يحط مفتاح**. التطبيق يكلّم سيرفرنا، والسيرفر يكلّم Claude بمفتاحك أنت، وأنت تدفع الفاتورة الشهرية.

```
تطبيق أندرويد ──(رسائل + سياق اليوم + صورة اختيارية)──► سيرفر سند /api/v1/coach ──► Claude API
                 ◄──────────────── رد + أزرار (سجّل الأكل، ابدأ تمرين…) ────────────
```

## الحماية من الفواتير المفاجئة

| الطبقة | شنو تسوي | وين تنضبط |
|---|---|---|
| حد الإنفاق الشهري | Anthropic توقف الطلبات إذا وصلت الحد — **هذا السقف الحقيقي** | لوحة Anthropic ← Limits |
| حد يومي لكل جهاز | ٤٠ رسالة و٨ صور باليوم لكل تثبيت (افتراضياً) | `DAILY_MESSAGES`، `DAILY_PHOTOS` |
| سقف يومي كلي | عدد طلبات لكل المستخدمين باليوم (اختياري) | `GLOBAL_DAILY_CAP` |
| مفتاح التطبيق | يمنع الاستعمال العشوائي للرابط | `SANAD_APP_KEY` |

ملاحظة صريحة: مفتاح التطبيق موجود داخل ملف APK، فالشخص الخبير يقدر يطلعه. لهذا الحدود اليومية وحد الإنفاق الشهري هم الحماية الأساسية، مو المفتاح.

العدّ اليومي يكون دقيق بين كل نسخ السيرفر إذا ربطت Upstash Redis (مجاني للاستعمال الصغير). بدونه العدّ يصير بذاكرة السيرفر، وهذا أقل دقة.

## التكلفة التقديرية

الأسعار من جدول Anthropic (لكل مليون توكن). التقدير لرسالة عادية: حوالي ٢٬٥ ألف توكن مدخلات غير مخزّنة (السياق والمحادثة)، و٢٬٢ ألف توكن تعليمات مخزّنة (cache)، و٤٠٠ توكن رد. الصورة تضيف حوالي ١٬٦ ألف توكن مدخلات.

| النموذج (`COACH_MODEL`) | السعر (مدخلات / مخرجات) | الرسالة تقريباً | مستخدم نشيط بالشهر* |
|---|---|---|---|
| `claude-opus-5` (الافتراضي، الأقوى) | ‎$5 / $25 | ‎~$0.024 | ‎~$3 |
| `claude-sonnet-5` | ‎$2 / $10 | ‎~$0.010 | ‎~$1.2 |
| `claude-haiku-4-5` (الأرخص) | ‎$1 / $5 | ‎~$0.005 | ‎~$0.6 |

\* مستخدم نشيط = ٤ رسائل باليوم وصورة كل يومين (١٢٠ رسالة و١٥ صورة بالشهر). هذي تقديرات. الرقم الحقيقي يطلع بلوحة Anthropic بعد أول أسبوع.

أسوأ حالة لمستخدم واحد يستهلك الحد اليومي كامل (٤٠ رسالة × ٣٠ يوم) على Opus 5 تقريباً ‎$29 بالشهر، ولهذا ضروري تحط حد إنفاق شهري.

الاستضافة: خطة Vercel المجانية (Hobby) للمشاريع غير التجارية فقط. للتطبيق التجاري تحتاج خطة Pro (‎$20 بالشهر). Upstash مجاني للاستعمال الصغير.

## خطوات التشغيل (مرة وحدة)

1. **مفتاح Claude**
   - من console.anthropic.com ← API Keys ← أنشئ مفتاح.
   - من Limits حط حد إنفاق شهري، مثلاً ‎$50 للبداية.
2. **رفع السيرفر على Vercel**
   - من vercel.com ← Add New Project ← اختار مستودع `-stmrarapp` (الجذر، مشروع Next.js).
   - بـ Environment Variables أضف:
     - `ANTHROPIC_API_KEY` = مفتاح Claude.
     - `SANAD_APP_KEY` = كلمة سر طويلة عشوائية (مثلاً ٣٢ حرف).
     - اختياري:
       - `COACH_MODEL`: النموذج (الجدول فوق).
       - `DAILY_MESSAGES` و`DAILY_PHOTOS`: الحدود اليومية لكل جهاز.
       - `GLOBAL_DAILY_CAP`: السقف اليومي الكلي.
   - اضغط Deploy وخذ الرابط، مثل `https://sanad-xyz.vercel.app`.
3. **(اختياري) عدّ دقيق**
   - من Vercel ← Storage/Marketplace ← Upstash Redis.
   - يضيف `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` تلقائياً.
4. **ربط التطبيق** من GitHub ← المستودع ← Settings ← Secrets and variables ← Actions:
   - بتبويب Variables: `SANAD_API_URL` = رابط Vercel.
   - بتبويب Secrets: `SANAD_APP_KEY` = نفس الكلمة اللي بخطوة ٢.
5. **نسخة جديدة**
   - أي push جديد يبني APK بيه المدرب السحابي مفعّل.
   - من شاشة المدرب ← الإعدادات، يطلع «المدرب الذكي شغّال».

## السلوك داخل التطبيق

- **الترتيب:**
  1. إذا المستخدم حط مفتاحه الخاص، يستعمل مفتاحه.
  2. إذا ما حط مفتاح، يستعمل سند السحابي.
  3. إذا ماكو سحابة بهذي النسخة، يشتغل المدرب المحلي.
- **إذا صار خطأ** (لا إنترنت، أو خلص الحد اليومي، أو السيرفر معطّل): يرد المدرب المحلي ويوضح السبب بجملة.
- **شنو يروح للسيرفر:**
  - معرّف تثبيت عشوائي (UUID).
  - آخر ١٦ رسالة.
  - ملخص أرقام اليوم.
  - صورة الوجبة إذا أرسلها المستخدم.
  - ماكو اسم حساب ولا رقم تلفون.
- **التعليمات:** نفسها بالتطبيق والسيرفر. يولّدها `node scripts/sync-coach-prompt.mjs` من `CoachPrompt.kt`، واختبار CI يفشل إذا اختلفت.
